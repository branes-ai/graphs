# Changelog 2026-05-18

Two-day arc spanning 2026-05-17 → 2026-05-18 that closes 5 successive
sprints: the DSP schema extension (`#211`), three NEAR_UNIFIABLE
follow-ups to v8 unification (v9 ThermalProfile / v10 OnDieFabric /
v11 DramAttachment), the v11 → v12 lockdown transition, and the
9-SKU DSP follow-up data sprint (`#223`).

The catalog reaches its richest schema state to date:
``compute_block_common`` hosts 4 re-exported primitives + 3 unified
types (TheoreticalPerformance v8 alias, ThermalProfile v9 alias,
OnDieFabric v10 inheritance base) + 1 cross-kind discriminator
(DramAttachment v11/v12). DSPBlock is the 8th and final category
block kind — every architectural family is schema-complete. The
catalog grows from 22 → 31 ComputeProducts; every shipping DSP SKU
is YAML-backed via the new `dsp_yaml_loader`.

follow-up loader-rename PR):

## Added

### DSPBlock category schema (sprint `#211`)

- **`DSPBlock` + 4 sub-types + 2 enums** in `embodied-schemas#43`
  (~470 LOC). The **eighth and final category block kind** —
  closes the last schema gap. Multi-fabric (`compute_fabrics:
  list[DSPComputeFabric]` always plural), `deployment_kind`
  discriminator (`STANDALONE_IP | SOC_INTEGRATED`), explicit
  `external_dram_bandwidth_kind: typical | measured` (load-bearing
  for IP-core vs SoC distinction), multi-profile DVFS via
  `thermal_profiles: list`, optional `vliw_issue_width`. First
  block kind to use `compute_block_common` from day 1 (no
  per-architecture `*TheoreticalPerformance` alias needed).
- **`dsp_yaml_loader`** at
  `src/graphs/hardware/models/ip_cores/dsp_yaml_loader.py` (~440
  LOC; `graphs#213`). Mirrors `tpu_yaml_loader` / `dpu_yaml_loader`
  patterns. Honors YAML's `default_precision` (DSPs span FP32 →
  INT8); no tile-energy decomposition; no SoCFabricModel; first
  loader to use `compute_block_common` from day 1.
- **Cadence Tensilica Vision Q8 YAML** at
  `data/compute_products/cadence/cadence_vision_q8.yaml` —
  reference SKU establishing the schema; first SKU exercising
  `external_dram_bandwidth_kind: typical`. New `cadence/` vendor
  directory. New `ip_core` value in the `model_tier` vocabulary.

### v9 unified ThermalProfile (sprint `#215`)

- **`ThermalProfile`** added to `compute_block_common` in
  `embodied-schemas#45` (9 fields + 1 validator). Collapses the 5
  byte-identical inference-accelerator `*ThermalProfile` classes
  (NPU/CGRA/DPU/TPU/DSP) into one shared type. Per-block-kind
  aliases in `embodied-schemas#46`. CPU and GPU
  `*ThermalProfile` stay separate by design (per-cluster
  `ClockDomain` on CPU; `ClockDomain` + `memory_clock_mhz` +
  `native_acceleration_by_precision` on GPU). Net **−179 LOC** of
  duplicated class bodies removed.

### v10 OnDieFabric inheritance base (sprint `#217`)

- **`OnDieFabric`** added to `compute_block_common` in
  `embodied-schemas#47`. **First inheritance-based** unification
  (v8 + v9 used aliases). Shared base carries the 7 fields all 6
  block-kind NoCs share + 2 optional mesh dims + optional
  confidence; per-block-kind subclasses contribute only the typed
  `topology` enum (architecture-specific: CPU's `infinity_fabric`,
  DPU's `aie_mesh`, NPU's `systolic`, etc.).
- **6 subclass migrations** in `embodied-schemas#48`. Net −92
  LOC schema; `*OnDieFabric` bodies shrink from ~25-30 LOC to ~5
  LOC. CPU + GPU subclasses also rename `stop_count` /
  `controller_count` → `unit_count` (matching the 4-of-6
  convention). YAML migrations: `intel_core_i7_12700k`,
  `jetson_agx_orin_64gb`, `jetson_agx_thor_128gb`.

### v11 DramAttachment discriminator (sprint `#219`)

- **`DramAttachment` enum** (`CHIP_ATTACHED | HOST_BUS`) added to
  `compute_block_common` in `embodied-schemas#49`. Captures the
  architectural distinction the v8/v9/v10 paper exercises
  repeatedly flagged: chip-attached vs host-bus external DRAM
  have different bandwidth and energy/byte cost models.
- **`dram_attachment` field** added to all 5 `*MemorySubsystem`
  classes (NPU/DPU/TPU/DSP/CGRA). Optional in v11 for backward
  compat; required in v12 after backfill.
- **CGRA naming reconciliation** in `embodied-schemas#50`:
  rename `has_host_dram`/`host_dram_*` → `has_external_dram`/
  `external_dram_*` on `CGRAMemorySubsystem`. Plasticine v2 YAML
  migrated atomically with `dram_attachment: host_bus` to
  preserve the "via PCIe" semantic the original naming captured
  implicitly. **First hard schema break** in the unification
  series.
- **Graphs-side follow-up** (`graphs#221`): bundled v11 CGRA
  loader update + 2 v10 stragglers (GPU + CPU loaders still
  reading `controller_count` / `stop_count`). Single CI pin bump
  catches all three.

### v12 DramAttachment backfill + lockdown (sprint `#222`)

- **`dram_attachment: chip_attached`** backfilled on the 4
  chip-attached YAMLs (`hailo_10h`, `vitis_ai_b4096`, `tpu_v4`,
  `cadence_vision_q8`) in `embodied-schemas#51`. Adds a
  regression test that walks the catalog and asserts every
  external-DRAM SKU populates the discriminator.
- **`_validate_external_dram_consistency` tightening** across all
  5 `*MemorySubsystem` classes in `embodied-schemas#52`. Requires
  `dram_attachment` when `has_external_dram=True`; rejects when
  False. The v11 optional+None pattern is gone; future SKUs are
  forced to populate the discriminator.

  - First multi-fabric (Synopsys EV7x VPU + DNN)
  - First `deployment_kind=SOC_INTEGRATED` + first
    `external_dram_bandwidth_kind=measured` (TDA4VM)
  - First multi-profile DVFS DSP (TDA4VM 10W/20W)
  - First `vliw_issue_width=8` (C7x VLIW; TDA4 family)
  - First `DSPFabricKind.VLIW_SCALAR` use (TDA4 family)
  - First `LPDDR5` on DSP (TDA4VH)
  - First 3-profile DVFS DSP (SA8775P 20W/30W/45W)
  - First TSMC N5 DSP (SA8775P)
  - First Hexagon DSP (SA8775P)
  - First `vliw_issue_width=4` (Hexagon; SA8775P)
  - First INT4 in `theoretical_performance` (CEVA NPM11)
  - First TSMC N6 SKU in the catalog (QCS6490)
- **TSMC N6 process node** added in `embodied-schemas#61`. DUV-only
  enhanced FinFET (~12% density + ~15% energy improvement vs N7).
  Same metal stack as N7; designs port easily. Used by
  Snapdragon 778G/695G/480 and edge-AI SoCs.
- **BOM overlay pattern** established by SA8775P, validated on
  QRB5165 + QCS6490. Wrapper attaches `bom_cost_profile`
  post-load because YAMLs don't carry BOM:
  ```python
  def qualcomm_sa8775p_resource_model():
      model = load_dsp_resource_model_from_yaml(...)
      model.bom_cost_profile = _SA8775P_BOM_COST_PROFILE
      return model
  ```
- **Tensor-first fabric ordering** convention established. CEVA
  NPM11 demonstrated zero structural drift when the primary
  tensor fabric is `fabric[0]`; subsequent multi-fabric SKUs
  (SA8775P, QRB5165, QCS6490) all use HMX/HTA-first ordering.

### `INT32` precision in dsp_yaml_loader

Bundled into `graphs#224` (EV7x cleanup): `INT32` added to the
`_PRECISION_BY_NAME` dict. Synopsys EV7x VPU fabric uses INT32;
without this, every TI TDA4 SKU's C7x fabric would also have
failed to load (they all carry INT32). Unblocks the entire
TDA4 batch.

## Changed

### Module docstring evolution

`embodied-schemas/src/embodied_schemas/compute_block_common.py`
docstring now reflects the 4 successive sprints (v8/v9/v10/v11)
that landed types in the module. Each unified type lists its

### Process node correction (TI TDA4 family)

All 4 TI TDA4 SKUs' hand-coded factories used `process_node_nm=28`,
but the same factories' docstrings explicitly say "Process: 16nm
FinFET" per TI's official Jacinto 7 documentation. YAML uses the
corrected `tsmc_n16`; cleanup PRs document as a YAML correction.
`energy_per_flop_fp32` collapses from the buggy 3.6 pJ (28nm)
to 2.43 pJ (16nm simd_packed baseline).

## Fixed

### Hand-coded factory bugs surfaced + corrected during cleanup PRs

- **TI TDA4 family `process_node_nm=28`** — same factory's docstring
  says "16nm FinFET". All 4 cleanup PRs (TDA4VM/AL/VH/VL) collapse
  to 2.43 pJ (16nm correct) post-cleanup.
- **TI TDA4AL/VH/VL `threads_per_unit=250`** — that's an
  ops_per_clock value pasted into the thread-count field.
  Post-cleanup all 3 use the loader's standard
  `wave_quantization` value.
- **TI TDA4AL/VH/VL `warp_size=1`** — probably forgotten. Post-
  cleanup uses `=compute_units` from loader convention.
- **TI TDA4AL/VH/VL `precision_profiles` sparse** — only INT8/FP32
  despite C7x + MMA supporting all of INT8/INT16/FP16/FP32.
  Post-cleanup includes full 4-precision set.
- **Catalog count assertions in 9 test files** loosened from `== N`
  to `>= N` subset semantics following the established pattern.

### CodeRabbit-flagged items addressed

- **DSPBlock vliw_issue_width validation** — added `ge=1`
  constraint when set (None still valid for non-VLIW DSPs).
- **DSPBlock external_dram_access_energy in validator** — added to
  the `has_external_dram` consistency check on both branches.
- **Cap thermal_profiles at 1-3** — skipped with rationale; prior
  block kinds (TPU/DPU/GPU/CPU) don't cap; brittle for hypothetical
  4+ thermal mode SKUs.
